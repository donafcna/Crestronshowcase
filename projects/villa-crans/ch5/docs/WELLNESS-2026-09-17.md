# Wellness — GUI 1.0.180 / contrat v4

Autorisation de Donatien : trois onglets HVAC, Sauna, Hammam dans la pièce équipée, sur dalle, tablette et téléphone. Le décor 3D reste exclusivement le fond du showcase.

## Configuration

Source : `projects/villa-crans/ch5/villa_config.json`, `pieces[id=13].pilotages.wellness`. Sauna et hammam sont des circuits séparés du HVAC, OFF au démarrage. Le HVAC normal reste 16–28 °C par pas de 0,5 °C ; le preset global historique hors gel à 12 °C est conservé. Par défaut sauna 60–100 °C, pas 1 °C, cible 80 °C ; hammam 90–100 % HR, pas 1 %, cible 95 %. Plages et cibles sont explicites dans le JSON. Aucun ventilateur sauna/hammam, aucune consigne de température hammam. Ces valeurs de démonstration doivent correspondre aux capacités du contrôleur installé : les joins ne constituent pas un driver de générateur vapeur ni de poêle.

Les libellés physiques et activations existantes restent préservés. Le showcase possède 17 pièces dont un local technique ; le profil physique conserve ses 15 pièces. Copies vitrine générées par `sync-villa-crans.py`. Réception native CH5 : attributs statiques `receiveStateSelected`, mesures via `data-ch5-textcontent`. Le JavaScript wellness gère uniquement navigation, visibilité et traduction FR/EN/DE/ES/RU.

## Joins GUI et EISC

Les appuis GUI sont globaux et le C# maintient la pièce propre à chaque écran. Base de pièce EISC : `1000 + (id - 1) * 100` ; pièce 13 = 2200. `blocsPiecesGui.actif` reste false.

| Fonction | GUI | Offset EISC de pièce | Valeur |
|---|---|---|---|
| Sauna ON / OFF / + / − | d620 / 621 / 622 / 623 | +11 / 12 / 13 / 14 | Appuis ; états ON/OFF exclusifs |
| Hammam ON / OFF / + / − | d624 / 625 / 626 / 627 | +15 / 16 / 17 / 18 | Appuis ; états ON/OFF exclusifs |
| Cible sauna | a62 / s62 | a+34 / s+44 | Analogique °C × 10 ; texte °C |
| Cible humidité | a63 / s63 | a+35 / s+45 | Pourcentage |
| Mesure sauna | a64 / s64 | a+36 / s+46 | Analogique °C × 10 ; texte °C |
| Mesure humidité | a65 / s65 | a+37 / s+47 | Pourcentage |

Dans SIMPL, les impulsions globales d620–627 sont des **sorties EISC** nommées `Sauna_On_Cmd`, etc. Les cibles et états persistants de pièce sont disponibles séparément : `R13_Sauna_On_fb`, `R13_Sauna_Setpoint_fb#`, `R13_Hammam_Humidity_Setpoint_fb#`, etc. Les retours des équipements entrent via `R13_Sauna_On_Actual` (d2211), `R13_Hammam_On_Actual` (d2215), et les analogiques a2234–2237. La retombée d'un retour ON est traitée, pas uniquement son front montant. Les sorties séries s2244–2247 préservent le join HVAC existant s2234.

La sélection ON après un appui représente la commande mémorisée par le C# jusqu'au retour équipement. Les mesures physiques restent `--` tant qu'aucun driver ne les fournit ; elles ne sont jamais simulées sur le CP4. La simulation de température/humidité est limitée à `local-feedback.js` sur le site.

## Livraison et recette

`Claude outputs/room-revision/livraison` contient JSON, CH5Z assemblé, CPZ compilé et une copie SMW préparée. Les anciens binaires locaux et le projet SIMPL ouvert ne sont pas écrasés. **LPZ non compilé ; aucun matériel déployé ou vérifié.** Compiler le SMW dans SIMPL Windows et raccorder les signaux aux drivers avant la recette physique. Ne pas réutiliser l'ancien LPZ comme s'il contenait ces joins.

Dans Debugger, tester d'abord la pièce 13 et surveiller Room_Select# : d620/621 puis d624/625 doivent produire des impulsions distinctes, sans verrouiller les sorties globales à 1. Vérifier les sorties persistantes R13 et les cibles 800 / 95. Injecter a2236=785, a2237=98 : affichages 78,5 °C / 98 %. Faire retomber d2211 et d2215 : les boutons OFF doivent s'activer. Vérifier les bornes et un second écran sur une autre pièce. État visuel du navigateur ≠ preuve de câblage matériel.

Tests reproductibles : `tools/test-wellness.ps1`, `tools/test-hvac.ps1` depuis le dossier CH5, et `apps/showcase/scripts/test-wellness-controls.cjs` depuis le site. Le premier accepte `-SimplFile <copie.smw>`. La matrice navigateur couvre les trois thèmes et supports, les modes normal/Scène et les pages directes, les bornes, traductions, retours natifs sans simulateur, contraste et cibles tactiles.
